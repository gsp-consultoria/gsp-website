# About Spec

## Objetivo

Apresentar a GSP Consultoria como uma parceira tecnica com visao de negocio.

## Direcao de copy

Evitar tom excessivamente pessoal. A secao deve vender a empresa, a capacidade tecnica e o metodo.

## Conteudo atual

- Headline: tecnologia com visao de negocio.
- Texto sobre engenharia de software, arquitetura e experiencia pratica em sistemas corporativos.
- Indicadores: mais de 5 anos de experiencia e 100% codigo proprio.
- Texto de apoio sobre reduzir retrabalho, integrar sistemas, melhorar controle operacional e criar bases tecnicas solidas.
- Pilares: Diagnostico claro, Entrega incremental, Codigo sustentavel.

## Comportamento visual

- Animacoes de entrada laterais com `framer-motion`.
- Grid responsivo em duas colunas no desktop.
- Card escuro/translucido para reforco de posicionamento.

## Criterios de aceite

- Texto nao parece curriculo.
- Reforca confianca.
- Mantem foco em solucao para cliente.
- Pilares devem ser legiveis em telas menores.
