# Technologies Spec

## Objetivo

Mostrar stack e capacidade tecnica sem transformar a secao em lista vazia de buzzwords.

## Tecnologias atuais

- React
- TypeScript
- AWS
- Azure
- Tailwind
- Vite
- .NET
- PostgreSQL
- Docker
- Git
- GitHub

## Elementos

- Titulo sobre stack moderna, pragmatica e preparada para escala.
- Texto de apoio sobre escolha de tecnologias conforme o problema.
- Marquee horizontal com icones de tecnologia.
- Duplicacao da lista em tempo de renderizacao para manter loop continuo.
- Pausa da animacao no hover.
- Fades laterais para suavizar entrada e saida dos icones.

## Fonte de conteudo

Estado atual: a lista de tecnologias esta declarada em `src/components/sections/Technologies.tsx`.

Evolucao recomendada: migrar a lista para `src/data/technologies.ts` quando houver nova manutencao de conteudo.

## Criterios de aceite

- Usa icones reconheciveis de `react-icons`.
- Layout nao rouba protagonismo da proposta de valor.
- Marquee deve permanecer fluida e pausar no hover.
- A lista deve refletir tecnologias realmente plausiveis para a oferta da consultoria.
